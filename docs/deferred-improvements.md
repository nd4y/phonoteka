# Отложенные доработки и проверки

Дата: 20.10.2026. По решению владельца сейчас приоритет - организованная копия коллекции и отчет по нерешенным файлам. Этот список сохраняет идеи и незавершенные проверки для отдельного обсуждения; он не является новым согласованным объемом разработки.

## Что отложено

| Направление | Что рассмотреть позже | Текущий статус |
| --- | --- | --- |
| Источники файлов | Google Drive, Яндекс Диск, Облако Mail.ru, S3, удаленные пути и импорт каталога с устройства пользователя; учет доступа, синхронизация и разрешение конфликтов | Только проектирование, реализация не согласована |
| PWA на телефоне | Установка, обновление установленного приложения, возврат после выгрузки и работа при потере сети на реальном Android | Остаточная ручная проверка; серверная проверка manifest/service worker не заменяет ее |
| Авторизация и кэш интерфейса | Поведение открытых экранов, черновиков и плеера при истечении/потере сеанса, выходе и повторном входе | Незавершенная браузерная проверка; браузер пока исключен из текущего этапа |
| Плеер и мобильная навигация | Итоговая проверка управления очередью, предыдущего/следующего трека, кнопки «Назад», сохранения контекста и компоновки на телефоне | Основная реализация есть; отдельная финальная проверка позже, дальнейшая полировка по результату |
| Дизайн и анимации | Дополнительная полировка существующего оформления и переходов после приемки основного сценария | Не должно задерживать обработку коллекции |
| Poweramp | Реальный импорт итогового пакета, обложек и синхронизированных текстов на телефоне владельца | Владелец отложил до конца; не считать пройденным по проверке файлов на сервере |
| Качество музыкальных таймкодов | Независимое прослушивание музыкального пилота и оценка точности строк | Владелец отложил до конца; технический успех ASR не означает подтвержденную точность на каждой песне |

## Что остается в текущей работе

- Завершить обработку копии, проверить записанные теги/обложки/тексты и подготовить итоговый перечень нерешенных файлов с причинами.
- Исправлять приложение при реальных ошибках чтения, преобразования, распознавания, записи и продолжения задач, которые мешают этому результату. Проверять исправления на build-01, не затрагивать чужие сборки и не менять оригиналы.
- Не подменять уверенное распознавание первым результатом поиска, не придумывать текст и таймкоды. Сомнительные совпадения и недоступные данные отражать в отчете.

Однопользовательский режим с авторизацией сохраняется. Публичный многопользовательский сервис не входит в план. Новые улучшения добавлять сюда с основанием и статусом, не смешивая их с исправлениями, необходимыми для текущей коллекции.
