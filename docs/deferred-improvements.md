# Отложенные доработки и проверки

Дата: 20.10.2026. По решению владельца сейчас приоритет - организованная копия коллекции и отчет по нерешенным файлам. Этот список сохраняет идеи и незавершенные проверки для отдельного обсуждения; он не является новым согласованным объемом разработки.

Актуализация 22.10.2026: владелец разрешил браузер и указал Edge. Плеер/CUE, Back, dirty/reload, live actions/отмена и согласованные размеры проверены; запуск установленной PWA отдельным приложением подтвержден владельцем. Старые формулировки «браузер исключен» и «финальная проверка позже» в срезе ниже больше не описывают весь текущий статус. Остаются browser offline/logout и реальный Android/Poweramp/музыкальная приемка. См. [протокол](browser-acceptance-2026-10-22.md).

| Качество музыкальных таймкодов | Независимое прослушивание музыкального пилота и оценка точности строк | Владелец отложил до конца; технический успех ASR не означает подтвержденную точность на каждой песне |

## Что остается в текущей работе

- Завершить обработку копии, проверить записанные теги/обложки/тексты и подготовить итоговый перечень нерешенных файлов с причинами.
- Исправлять приложение при реальных ошибках чтения, преобразования, распознавания, записи и продолжения задач, которые мешают этому результату. Проверять исправления на build-01, не затрагивать чужие сборки и не менять оригиналы.
- Не подменять уверенное распознавание первым результатом поиска, не придумывать текст и таймкоды. Сомнительные совпадения и недоступные данные отражать в отчете.

Однопользовательский режим с авторизацией сохраняется. Публичный многопользовательский сервис не входит в план. Новые улучшения добавлять сюда с основанием и статусом, не смешивая их с исправлениями, необходимыми для текущей коллекции.


## Предложения ревью 22.10.2026 - не реализованы

- Регулярный advisory/container OS scan и SBOM в CI: ручной npm/OSV scan выполнен для текущих pins, GitHub alerts выключены. Постоянную автоматизацию и настройки репозитория отдельно согласовать; не объявлять ручной scan постоянным контролем.
- Разделение frontend bundle: production build предупреждает о JavaScript chunk около 524 КБ (154 КБ gzip). Измерить реальное время старта на телефоне и только затем решать, нужно ли разделение; порог bundler сам по себе не доказывает плохую работу интерфейса.
- Внешний ASR по CHG-040 и полный OpenTelemetry по P2 остаются отдельными согласуемыми работами. Их нельзя незаметно включать для отметки Production Ready или в обход разрешения на передачу аудио.

Исправления обнаруженных дефектов очереди/SSE/auth и security pins входят в текущий выпуск ревью и не относятся к этим предложениям.
