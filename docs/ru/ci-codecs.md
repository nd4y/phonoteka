# Медиазависимости CI

`dev/install-ci-codecs.sh` проверяет FFmpeg, FFprobe, `fpcalc` из Chromaprint и загрузку `libebur128.so.1`. Если работают все четыре компонента, CI продолжается без обновления индексов посторонних пакетов. Иначе нужные пакеты устанавливаются по имеющимся индексам; после неудачной установки допускаются одно обновление индексов и ещё одна попытка установки.

Задание Ubuntu 24.04 передает `dev/ubuntu-ci.sources` через `CODEC_APT_SOURCES`. Пакетные команды используют только официальные HTTPS-репозитории Ubuntu для основных пакетов и обновлений безопасности, со штатным ключом архива Ubuntu. Это исключает медленное HTTP-зеркало исполнителя без отключения TLS и проверки подписей пакетов. Список действует только для этих команд; системные файлы репозиториев не переписываются. Отсутствие указанного списка завершает шаг до обращения к запасным репозиториям.

На каждую пакетную команду отводятся три минуты; сетевые повторы ограничены. Итоговая проверка программ и библиотеки обязательна. Недоступный репозиторий или отсутствующий инструмент приводят к ошибке задания, а не к пропуску медиатестов. Вывод пакетного менеджера сохраняется, чтобы отличать сбой окружения от ошибки продукта. Меняется только подготовка исполнителя GitHub, без изменения пакетов приложения и конфигурации хостов.
