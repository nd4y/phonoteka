# Русское распознавание на существующем ASR-движке

После завершения дерева принадлежащих запросу процессов очистка временных файлов
повторяет временную ошибку доступа Windows не более шести раз, с суммарной
задержкой до 7,4 секунды. Блокировка GPU и счётчики запроса удерживаются до конца
очистки. Постоянная ошибка доступа и другие ошибки файловой системы не скрываются.
Приёмка отмены проверяет реальные PID дочерних Python-процессов, память GPU и
временные файлы, а не только нулевой счётчик активности.

Необязательный профиль `PC2_ASR_RUSSIAN_MODEL=gigaam-v3-e2e-rnnt` использует GigaAM
для независимого распознавания русской речи. При явном выборе русского языка
запрос сразу направляется в GigaAM. Автоопределение сначала использует прежний
многоязычный распознаватель; если он определил русский, распознавание повторяется
через GigaAM. Для остальных языков сохраняется прежний Whisper. При пустой
переменной поведение не меняется. Выбранная, но недоступная или неподходящая
модель возвращает явную ошибку.

GigaAM предоставляет реальные времена начала и конца слов, но не акустическую
вероятность каждого слова. UI показывает неизвестную уверенность отдельно;
выдуманных оценок нет. Полные совпадения строк с эталоном дают независимые опоры
по словам. Окончательное выравнивание выполняет Whisper с прежними проверками
средней вероятности, порядка времени, длины окна и близости к независимой опоре.
Пропуски не заполняются интерполяцией. Даже полное покрытие остаётся черновиком
для проверки; слова, таймкоды, инструментальность и изменения файла автоматически
не подтверждаются.

## Контракт и движение данных

Клиент использует существующий защищённый HTTPS-адрес движка, ключ и совместимый
префикс `/v1/whisper`. Новый публичный порт и исключение авторизации не нужны.
Health отдельно объявляет необязательный распознаватель; запрос явно выбирает
модель. GigaAM использует прежние общую блокировку GPU, ограниченную очередь,
сроки выполнения, остановку дерева процесса и очистку временных данных.
Каждая модель работает в отдельном завершаемом процессе. Между распознаванием
и выравниванием модели освобождаются. Для распознавания передаётся только
аналитический PCM; для окончательного выравнивания - прежние короткие PCM-окна
и эталонные слова. Исходники приложения, метаданные и база коллекции на движок
не переносятся.

Закреплены GigaAM 0.2.0 и модель `v3_e2e_rnnt`:

- SHA-256 весов: `f60c62fe45902d967000770a12f260de7c5ac4d4b8e5e852f1df8c548e3958b5`.
- SHA-256 токенизатора: `828c12c991019eef952a960661f25a92d6ad279591e2ea466b4aeddf1d20a18a`.
- Вероятности слов отсутствуют. Оценки окончательного выравнивания предоставляет Whisper.

Файлы модели должны уже находиться в кеше движка. Процесс проверяет хеши и
блокирует сетевые соединения Python вместо скачивания модели во время запроса.
Включённый ресурсный профиль получает новый идентификатор: старый результат
Whisper для того же аудио не выдаётся за GigaAM. Прежние результаты и удержанные
задачи сохраняются в истории; выкладка их не перезапускает.

## Установка и приёмка

Перед обновлением существующего общего движка зафиксируйте точные хеши исходников
и сделайте защищённую копию. Установите принадлежность операции и отсутствие
работающих или ожидающих ASR-запросов, в том числе от других потребителей. При
нагрузке отложите обновление. Перенесите только общие `whisper_bridge.py` и
`gigaam_model_worker.py` из `integrations/pc2_asr`. Существующие сервер, процесс
Whisper, модели, ключ, TLS и конфигурация службы сохраняются. Исходники приложения
не передаются. Перезагрузите только существующую принадлежащую операции службу
при подтверждённом простое и проверьте обычный health и защищённый контракт
распознавателей. При ошибке верните точный прежний мост и выясните состояние
службы до повтора.

Затем обновите проверенную пару образов приложения и inference и включите
переменную для inference. Сохраните данные, очередь, трейсинг и доставку. Откат
возвращает прежние образы, конфигурацию и общий мост без подмены новых данных
коллекции и удаления прежних результатов ASR.

Для приёмки нужны точный CI-артефакт, отрицательные проверки идентичности и
контрактов, прежнее поведение английского языка, отмена с освобождением процесса,
памяти и временных файлов, а также две реальные русские песни через UI.
Запишите ревизию аудио, распознаватель, длительность операции, число сопоставленных
строк и оставшиеся пробелы. Синтетические тесты подтверждают контракт, но не
точность на музыке. Установленная версия и реальные пилоты проверяются отдельно
от исходников и сборки.

Экран проверки также отличает актуальное предложение без новых изменений от
предложения для старой ревизии файла. Ограниченные данные остаются ограниченными;
выбор разрешённого и проверенного источника выполняется отдельно.
