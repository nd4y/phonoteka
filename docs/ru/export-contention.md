# Прогресс экспорта при занятой базе

`EXPORT-PROGRESS-BUSY-01`: счётчик скопированных файлов служит для отображения прогресса. Временная ошибка SQLite BUSY или LOCKED при сохранении счётчика оставляет на экране предыдущее значение и позволяет продолжить копирование. Откатившаяся транзакция закрывается; следующий замер использует новую транзакцию. Частота обновлений остаётся ограниченной.

Обработка занятости действует только для счётчика. Проверка прав, SHA исходного и скопированного файла, происхождения данных и ревизий, фиксация снимка и завершение задачи сохраняют прежние обязательные проверки. Другие ошибки базы по-прежнему завершают экспорт с ошибкой. Неудачная попытка не заменяет предыдущий неизменяемый снимок. JSON-журнал сохраняет числовой код SQLite без сообщения, SQL-запроса и закрытых путей. Настройки трейсинга не меняются.

Приёмка: `tests/test_export_contention.py` удерживает настоящую блокировку записи SQLite при начальном, промежуточном и последнем обновлении прогресса, затем проверяет байты снимка и единственный успешный результат задачи. Ошибка базы, не связанная с занятостью, должна завершить экспорт с ошибкой и сохранить предыдущий снимок. `tests/test_observability.py` проверяет отсутствие текста SQL в журнале. Экспорт установленной коллекции проверяется отдельно после выпуска.
