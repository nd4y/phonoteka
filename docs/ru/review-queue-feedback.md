# Подписи действий в очереди проверки

Пропуск открывает следующую запись из выбранной очереди. Пока она загружается, кнопка сообщает об открытии следующей записи. Сообщение о записи файла не показывается, задача применения изменений не создаётся.

Действие «Записать и дальше» сохраняет сообщение о записи, пока выполняется явно запрошенное применение. Оба перехода блокируют повторное действие до своего завершения. Границы очереди, проверки отмены, правила принятия данных и публикация сохраняются.

Приёмка включает задержанное чтение следующей карточки: переход остаётся видимым, запрос применения не отправляется. Существующие тесты проверяют границы очереди и ожидание записи; установленный интерфейс проверяется отдельно от CI.
