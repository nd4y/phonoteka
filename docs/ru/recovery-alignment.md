# Восстановление очереди и текст для ASR

Если обработчик остановился во время анализа метаданных, распознавания, проверки аудио, ASR, выравнивания, ReplayGain или поиска источника YouTube, при запуске задание переходит в состояние «Приостановлено». В «Обработке» нажмите «Продолжить». Уже завершённые элементы не выполняются повторно; прерванные элементы больше не отображаются как работающие. Запрошенная до сбоя отмена сохраняется. Счётчики провайдеров и неопределённые результаты запросов не сбрасываются.

Это восстановление не публикует файлы и не возобновляет сетевые запросы само. Для операций записи продолжает действовать сверка файлов и журналов; она не заменяется повтором задания.

Выравнивание использует только текст и связанные с ним ограничения источника. Просроченные предложения тегов или обложек не блокируют ASR текста. Для уже записанного в файл разрешённого текста срок HTTP-кэша не является сроком жизни файла. Отозванное разрешение и ограничения исходного текста продолжают проверяться перед постановкой и исполнением задания. Для ещё не записанного предложения текста срок кэша сохраняется.

Проверки: API допуска/отказа выравнивания, очистка очереди по политике источников, повторная проверка исполнителем, перезапуск с сохранением результатов, явное продолжение без повтора готового элемента, сохранение отмены и лимитов. Синтетические проверки не подтверждают музыкальную точность таймкодов.
