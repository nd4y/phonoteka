# Большие отчёты коллекции

Отчёты JSON и CSV сохраняют прежние поля и единый снимок чтения базы. Сервер полностью записывает отчёт во временный файл без имени до отправки HTTP-заголовков, затем передаёт его ограниченными порциями. Ошибка построения отчёта или временного хранилища не превращает частичный документ в успешное скачивание. Файл закрывается после завершения, сетевой ошибки или отмены.

Так в памяти не удерживаются одновременно полная строка JSON и её копия в UTF-8 для HTTP. Символ за пределами основной многоязычной плоскости Unicode может увеличить всю строку до четырёх байт на символ. Построение отчёта по-прежнему хранит выбранные поля коллекции; это изменение не гарантирует постоянный расход памяти при любом её размере. Временное хранилище должно вмещать отчёт; tmpfs также учитывается в лимите памяти контейнера.

Приёмка сравнивает байты JSON и CSV с прежним форматом, включая Unicode, защиту CSV от формул, политики источников и состояние публикации. Тесты проверяют ошибку построения и отмену ответа. Снимки аудио, аренды скачивания, контрольные суммы, политики провайдеров и трейсинг не меняются; повторно создавать существующий экспорт не требуется.

## Готовый снимок во время скачивания

`GET /api/exports/latest` также полностью сериализует ответ во временный файл без имени до отправки заголовков. Манифест, происхождение данных, квитанции, счётчики и признаки устаревших файлов сохраняют прежний формат JSON. FastAPI больше не копирует рекурсивно весь большой ответ и не создаёт полные строки Unicode и UTF-8 одновременно со скачиванием аудио.

Для отдельных файлов приложение хранит индекс одного снимка: пути, хеши и сведения о происхождении данных. Одновременные запросы используют одно начальное чтение. При каждом запросе сервер безопасно открывает манифест и проверяет размер; устройство, inode, размер, время изменения и ctime определяют актуальность индекса. Повторяющиеся пути отклоняются. Текущие разрешения источников и полный хеш аудио проверяются и при попадании в кеш. Удалённый манифест нельзя выдать из индекса. Потоковая выдача архива и аренды скачивания сохраняют прежние проверки.

Приёмка включает одновременные обращения к манифесту, равенство JSON с Unicode, конкурентную загрузку индекса, изменение аудио, отзыв разрешений и изменение манифеста того же размера с восстановленным mtime. Замеры памяти относятся к ограниченному тестовому набору; после них обязательна проверка выдачи реальной коллекции. Неограниченная вместимость не заявляется.
