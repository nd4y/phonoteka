# Подключение AcoustID

AcoustID дополняет распознавание Shazam: если нет однозначного совпадения и запись не отмечена как смесь композиций, задача «Распознать» вычисляет Chromaprint и ищет связанные записи MusicBrainz. Несколько совпадений остаются предложениями для проверки. Версия записи не считается подтверждённой, теги автоматически не записываются.

## Настройка через интерфейс

1. Зарегистрируйте приложение в [Your Applications](https://acoustid.org/new-application) и получите Application API key. User API key предназначен для отправки новых отпечатков и здесь не используется.
2. Войдите владельцем, откройте «Настройки», найдите карточку AcoustID в блоке музыкальных источников. Вставьте ключ, включите «Использовать AcoustID» и нажмите «Сохранить подключение».
3. Нажмите «Проверить подключение». Приложение отправит синтетический отпечаток; ответ без совпадения также подтверждает доступность API и принятие ключа. Проверка расходует один запрос суточного лимита.
4. Запустите «Распознать» для выбранных файлов. Сохранение настройки само по себе не создаёт задач и не повторяет обработку коллекции.

Передача отпечатков дополнительно требует серверного `EXTERNAL_FINGERPRINTS=true`. При запрете интерфейс объясняет причину. Кнопка проверки доступна после сохранения изменений. Пустое поле ключа при сохранении оставляет прежний ключ; удаление ключа одновременно выключает интеграцию.

## Данные, ограничения и ошибки

В AcoustID по HTTPS POST уходят ключ приложения, Chromaprint первых максимум 120 секунд и длительность всего файла. Аудио, имя файла и существующие теги не отправляются. Общая очередь запросов app/worker соблюдает интервал не менее 0,4 секунды; действуют суточный лимит и общий бюджет трёх отправок распознавания на аудиозапись. Новый провайдер не обнуляет бюджет. При исчерпании требуется ручное решение; при неизвестном исходе отправленного запроса автоматического повтора нет.

Ключ хранится в `/state/integrations/acoustid.json` с правами 0600, каталог - 0700. Обновление атомарно, конкурентная устаревшая форма отклоняется. API возвращает только наличие ключа, состояние и версию настройки. Ключ отсутствует в URL, БД, кешах, событиях и диагностике. Файл подключения следует сохранять только в защищённой резервной копии состояния. Установка нового образа с тем же `/state` сохраняет подключение; отдельного изменения compose для ключа не требуется.

Низкие оценки и отсутствие связанной записи MusicBrainz не считаются надёжным совпадением. Ошибки API, ограничения частоты и отказ доступа показываются отдельно от результата без совпадений. В ответе сохраняется не более восьми кандидатов с оценкой от 0,8. Это порог отбора предложений, а не вероятность правильности. Политика использования источников распространяется на эти предложения. Метаданные MusicBrainz и связи AcoustID имеют отдельные условия от аудио и обложек.

Документация: [API](https://acoustid.org/webservice), [данные и лицензии](https://acoustid.org/database). Бесплатный публичный API предназначен для некоммерческого использования.
