# Обновление устаревшего поиска текста

Подготовка коллекции включает отдельные песни, у которых не хватает только текста
с таймкодами, а прежний поиск текста устарел или относится к другой версии файла.
Нажмите **Проверить коллекцию**, проверьте отмеченные записи и запустите
**Подготовить данные**. Причина рядом с песней поясняет поиск по каталогам.
За один запуск обрабатывается не более 50 выбранных записей.

Новые запуски, которым нужен только текст, обращаются напрямую к LRCLIB. Они не
ждут MusicBrainz, обложки или дополнительные каталоги, если теги и обложка уже
заполнены. Прежние доказательства для той же версии файла сохраняют исходные
разрешения и срок хранения: поиск текста их не обновляет. Уже запущенные старые
партии сохраняют прежний состав запросов и квитанции. При ошибке LRCLIB остаются
обычные паузы перед повтором.

Используется существующий поиск с разрешениями, квотами, паузами и проверками
авторизации источников. Новые аудиоотпечатки не отправляются, потраченный бюджет
распознавания не сбрасывается. Существующие квитанции подготовки, включая
остановленные и неудачные попытки, запрещают автоматический повтор. Обновление
результатов не заменяет сохранённый черновик текста и не записывает теги, слова
или таймкоды в аудио.

Поиск проверяет пригодность таймкодов перед остановкой на первом результате.
Если поиск по альбому и треку не дал пригодных таймкодов, Фонотека может один
раз поискать в LRCLIB по названию и исполнителю в одной строке. Такой запрос
доступен и в плане для подтверждённой по отпечатку записи, когда прежний поиск
завершился без вариантов с таймкодами. Варианты обычного текста сохраняются.

Миксы, разговорные записи, подтверждённые инструменталы, закреплённый текст
и актуальные черновики с таймкодами исключаются. Сверьте слова и время с аудио
перед применением.
