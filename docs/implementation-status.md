# Статус реализации

Дата начала разработки: 18 октября 2026 года. Целевое ТЗ v1.4 сохранено. Текущий выпуск `0.1.0a1` представляет ручной цикл R1 и технические проверки R0; это не приемка полного v1.

| Область | Объем alpha | Граница проверки |
| --- | --- | --- |
| Авторизация | Один owner, Argon2, cookie, CSRF, ограничение попыток | Без регистрации, OIDC и внешних API-токенов |
| Коллекция | Сканирование копии, хеши, метаданные, поиск, страницы | Оригинал RO; неоднозначный перенос истории не выполняется |
| Очередь | Отдельный worker, ограниченные потоки, SQLite/WAL, отмена, progress | Не распределенный кластер |
| Ручное редактирование | Предложение тегов, обложки и LRC отдельно от применения | Не автоподбор внешними сервисами |
| Запись | MP3/FLAC в пределах проверенного профиля, хеш аудиопакетов, backup, журнал, CAS | Неподдерживаемые профили и другие форматы остаются RO |
| Аудит | Проверка декодирования FFmpeg | Не оценка художественного/исходного качества |
| Публикация | Копия принятой ревизии в отдельный Ready | Не доставка и не подтверждение воспроизведения на телефоне |
| Интерфейс | React/TypeScript, Material 3 Expressive, RU, светлая/темная тема | Рабочие данные API, отдельный прежний макет остается демонстрацией |
| Поставка | Docker amd64, GitHub Actions, тестируемый образ | Приватный репозиторий и внутренний proxy |

## Следующие этапы

- R0: отдельный музыкальный набор для проверки MP3/FLAC, gapless/timeline и офлайн Poweramp на устройстве; испытания аварийного питания файловой системы отличаются от остановки процесса.
- R2: ACRCloud/AudD, MusicBrainz/AcoustID, Cover Art Archive и LRCLIB; учет происхождения, лимиты, предложения и ручное подтверждение. Внешняя передача аудио включается явно после настройки ключей.
- R2: отдельный inference, faster-whisper и forced alignment, ограничения памяти, принятый текст и независимые проверки качества по ТЗ. До музыкального пилота автоматический quality gate выключен.
- R3: TheAudioDB/Discogs, дубликаты, комплектность альбомов, ReplayGain, расширенная публикация/доставка, согласованный backup/restore и эксплуатационные метрики.
- R4: OIDC, n8n webhooks и scoped API-токены, дополнительные форматные профили, договорные lyric-провайдеры.

84 критерия приемки ТЗ остаются целевыми требованиями. Зеленая сборка alpha подтверждает только перечисленные в ее тестах сценарии. Отчет конкретного развертывания фиксируется отдельно вместе с commit, workflow, image ID и проверками.
