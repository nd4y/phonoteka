# Статус реализации

Текущий выпуск: `0.2.0-alpha`. Целевое ТЗ v1.4 сохранено. Это работающий выпуск с каталогом, редактированием, внешними источниками и локальным ASR; приемка полного v1 еще не завершена. Подробные ограничения: [current-release.md](current-release.md).

| Область | Реализовано | Граница проверки |
| --- | --- | --- |
| Авторизация | Один владелец, Argon2, cookie, CSRF, ограничение попыток | Регистрация, OIDC и scoped API-токены отсутствуют |
| Коллекция | Сканирование копии по расширениям и содержимому, файлы без расширений, хеши, поиск по значениям тегов и CUE, Unicode-регистр | Оригинал RO; поврежденные файлы сохраняются с ошибкой |
| CUE | Альбомы, композиции, несколько FILE, UTF-8/UTF-16/Windows-1251, прослушивание по INDEX | Только чтение; разделение, индивидуальная запись и публикация образов не реализованы; см. [CUE](cue.md) |
| Очередь | Отдельный worker, ограниченные потоки, независимые очереди ASR и обычных задач, SQLite/WAL, отмена, восстановление после прерывания | Не распределенный кластер; незавершенные записи требуют сверки журнала |
| Источники | MusicBrainz, LRCLIB, Cover Art Archive, локальная обложка; кеш, дневной бюджет, ограничения частоты, пауза при отказах | Поиск по тексту не устанавливает идентичность аудиозаписи; результаты требуют проверки |

| Сопоставление текста | Whisper cross-attention/DTW с независимыми ASR-якорями; текст фиксируется при создании задания | Неуверенные строки остаются без времени; автоматическое принятие выключено |
| Предложения | Выбор метаданных/обложки/текста из источника, ручной редактор, импорт LRC/TXT, отдельное сохранение и применение | Обычный текст не становится синхронным без таймкодов; неподтвержденные изменения не применяются автоматически |
| Запись | MP3, FLAC, M4A/MP4, Ogg Vorbis, Opus, WAV и AIFF; проверка аудиопакетов и посторонних тегов, backup, журнал, контроль ревизии | Другие декодируемые профили доступны для чтения; изменение тегов не перекодирует аудио |

| Интерфейс | Material 3 Expressive, русский язык, светлая/темная темы, мобильная верстка, живые данные API | Прежний HTML-макет остается демонстрацией |

## Что подтверждают проверки

- Backend-тесты проверяют реальные кодеки, сохранность аудио/метаданных, ревизии, восстановление, CUE, ограничения внешних запросов, очереди и сценарии обнаружения файлов.
- GitHub запускает настоящий ASR на синтезированной речи, проверяет времена, дедупликацию заданий, положительное сопоставление эталонного текста и отказ от выдуманных времен для постороннего текста.
- Реальный ASR музыкального трека на st1 завершился, временные границы и входной SHA проверены. Это не доказательство точности всех слов или готовности караоке.
- Отчет конкретного развертывания хранит commit, GitHub run, image ID, checkpoint и отдельные результаты браузера, восстановления копии состояния и целостности коллекции.

## Внешние данные и приемка

Приложение допускает только официальные адреса MusicBrainz: основной и `beta.musicbrainz.org`. Официальный beta использует ту же живую базу с предварительной версией серверного кода. На st1 основной адрес сбрасывал соединение; beta, LRCLIB и CAA ответили по HTTPS. Проверка TLS сохранена, глобальная сеть не менялась.

Для запроса в каталоги используются названия, исполнитель, альбом и длительность; при отсутствии тегов возможна подсказка из имени файла. Аудио этим поиском не отправляется. Пакетный анализ личной коллекции в текущей сессии ожидает отдельного согласия после отклонения автоматической проверкой разрешений. Его выполнение и покрытие нельзя подменять успешными тестами адаптеров.

AudD/ACRCloud/AcoustID без ключей недоступны. Пользователь выбрал начать с бесплатных источников. Отдельный пилот передачи отпечатка в неофициальный ShazamIO также ожидает согласия; адаптер Shazam в рабочий образ не включен.

Остаются требования полного v1: музыкальный пилот качества ASR/выравнивания, физическая офлайн-проверка Poweramp, CUE-экспорт, ReplayGain, дополнительные адаптеры каталогов, подтверждение доставки, scoped API/webhooks и оставшиеся критерии ТЗ. Ни поврежденные файлы, ни неизвестные записи не должны отмечаться распознанными ради формального завершения очереди.
