## Что осталось для завершения v1

Конечный список: S1 новый frontend/GitHub gate после mobile CSS fix; S2 touch targets/accessibility/оставшиеся owner workflows и live observability; S3 полный NFR/ASR resource profile; S4 controlled st1 deploy/migration/restart/ACL/HTTPS и оставшиеся recovery boundaries; S5 свежий аудит и mixed package фактической коллекции; S6 независимый музыкальный пилот30+10; S7 actual one-way delivery20MP3/FLAC и offline Android/Poweramp. Browser player/jobs/PWA и NAS generated restore уже имеют указанные выше доказательства и не считаются непроверенными целиком. Точные пороги и соответствующие AC находятся в acceptance-audit.

Подтвержденных отсутствующих обязательных backend-маршрутов на текущем срезе не установлено. **Полное ТЗ не принято, уведомление «ТЗ выполнено» не отправляется.** Cloud/device file sources остаются только проектированием CHG-026. Optional OIDC/GPU/remote/keyed catalogs/webhook receiver не включаются ради отметки в таблице.

В `requirements-register.md` добавлена промежуточная CHECK-009; архивы ТЗ и `current-release.md` не изменены. Production статус0.6 отделен от новой реализации и ее приемочных результатов. Этот срез не закрывает выполняющийся NFR или будущий deployment.
