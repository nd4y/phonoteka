# Автоматизация и доставка

В настройках владелец создает API-токен: `read`, `jobs:analysis`, при необходимости `jobs:write`. Токен показан один раз, хранится только его хеш, срок 1-365 дней. `jobs:write` разрешает запись, откат, публикацию и производные копии; токен не управляет токенами/расписанием и не подтверждает личную проверку Poweramp. Отзыв или истечение останавливает новые эффекты его заданий. Уже начавшаяся атомарная операция завершается согласованно.

Для n8n сохраните токен в Credentials, используйте HTTP Request с `Authorization: Bearer ...`. Передавайте стабильный `Idempotency-Key` для одного запроса. Сначала `POST /api/v1/jobs` с `{"kind":"scan"}`, затем читайте `/api/v1/jobs/{id}`. После сканирования можно поставить `{"kind":"recognize","params":{"scope":"pending"}}` и `{"kind":"analyze","params":{"scope":"pending"}}`. Новые ключи нужны для новых заданий. Повтор запроса с прежним ключом не создает второе задание. Схема: `/api/openapi.json` после авторизации.

Состояние `queued` с этапом `waiting_provider` и `retry_at` означает сохраненный повтор после лимита/сбоя сервиса. Оно не является успешным завершением. Завершенные файлы не обрабатываются заново; очередь доступна другим заданиям во время ожидания. Суточный бюджет сохраняется. Shazam начинает с интервала 10 секунд и увеличивает его после HTTP 429, дополнительно соблюдая Retry-After.

Встроенное расписание выключено по умолчанию. Владелец выбирает период и этапы: scan, recognize, analyze, replaygain. Список файлов формируется после предыдущего этапа; уже обработанные пропускаются. Автоматической записи/публикации расписание не выполняет. Оно хранится в SQLite и переживает перезапуск. Отключение отменяет его незавершенные задания. Смена пароля отзывает grant расписания.

В Ready создайте экспорт: `export_ready`. Worker проверит SHA-256 каждого опубликованного актуального файла, создаст неизменяемые manifest.json и playlist.m3u8. Плейлист использует относительные UTF-8 пути и размещается в корне скопированной Ready. Переносите дерево Ready на телефон выбранным клиентом синхронизации. Ничего не удаляется автоматически.

Для подтверждения доставки загрузите JSON-словарь `{"относительный/путь.mp3":"sha256..."}`, полученный хешированием файлов **на принимающем устройстве**. Сервер требует полного совпадения списка и хешей экспорта. Не используйте серверный manifest вместо клиентского измерения. Отдельная отметка Poweramp доступна только владельцу после фактического офлайн-прослушивания, проверки обложки и синхронного текста. Запись хранит происхождение доказательства: сообщение клиента/владельца. Она не утверждает, что NAS самостоятельно проверил телефон. Изменение ревизии делает экспорт устаревшим.

Webhook и OIDC являются опциональными расширениями и в этом выпуске не включены. Для n8n доступно чтение статуса по API без них.
