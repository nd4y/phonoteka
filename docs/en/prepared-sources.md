# Prepared files and retained sources

Once audio recovery or CUE extraction creates its output files, the retained input is no longer an additional file to prepare. Collection completeness, audio audit counts, missing-data filters and new bulk/folder analysis work use the prepared files. The overview lists retained audio sources separately. All catalog records and source files remain accessible through the full collection and JSON/CSV reports; reports identify source records and their prepared track IDs.

This applies only while every declared output is a current catalog record with matching parent revision and export identity. CUE images also require every related sheet to be extracted from the current image revision. A missing output, different parent or stale revision restores the input to outstanding work. Files are never deleted, existing queued jobs are not rewritten, and provider limits are not reset.

These counters describe the files to prepare. They do not grant publication acceptance or confirm listening, lyrics timing or Poweramp playback.

Pending-search counts use the same source-validity rules as launching a job. An expired result counts as pending when the current policy permits fetching and retaining a replacement. A deliberate cache restriction does not trigger a repeat search. Updating the report never starts or replays processing.
