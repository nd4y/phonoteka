# Preparing missing artwork

Open Collection -> Needs review -> Fill confirmed fields and check the plan.
The preparation list may include recordings whose album artwork has not yet
been obtained. Select the intended recordings and start Prepare data. Their
explanation states that no new audio fingerprint is sent; results appear in
the recording's sources.

Preparation requires an already confirmed recording match in MusicBrainz.
The embedded album must exactly match a saved official release name. Without
an embedded album, all complete matching release lists must agree on one
album name. Single, Deluxe and Remaster suffixes are not stripped to make an
automatic choice. Truncated or conflicting evidence is rejected.

The new lookup is restricted to that album's releases and artwork. Existing
lyrics, ASR, fingerprints and their allowances are retained; the audio file is
not modified. Sources keep their existing cache, pacing and usage policy.
Any previous Cover Art Archive outcome, including errors and missing artwork,
requires review instead of this automatic retry. A newer failed search also
blocks this capability until examined.

Each preparation has its own receipt bound to the current revision, album and
field/proposal guards. Earlier receipts are retained. Failure or cancellation
does not create an automatic retry loop.

The resulting plan distinguishes absent image evidence from image candidates
whose edition remains unconfirmed. Preparation is not artwork acceptance:
compare the results. Application and publication still enforce current
revisions, source usage, edition evidence, saved decisions and image slots.
Mixes, speech, conflicts and unsettled operations remain blocked.
