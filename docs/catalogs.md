# Дополнительные каталоги

MusicBrainz/LRCLIB/CAA и Shazam включаются прежними отдельными флагами. Дополнительные назначения по умолчанию выключены. Для текущего экземпляра согласованы только первые четыре сервиса; TheAudioDB/Discogs не используются для коллекции без отдельного включения владельцем.

`THEAUDIODB_ENABLED=true` разрешает поиск альбома через официальный v1 API с публичным free key 123, интервал не менее 2.1 секунды. Результат является кандидатом издания. `THEAUDIODB_ARTWORK=true` дополнительно разрешает загрузку обложки с официальных image-hosts. Источник/атрибуция сохраняются; наличие картинки не доказывает конкретное издание. [Документация API](https://www.theaudiodb.com/free_music_api), [условия](https://www.theaudiodb.com/docs_terms_of_use.php).

Для Discogs задайте `DISCOGS_ENABLED=true`, смонтируйте личный token-файл только app/worker и задайте `DISCOGS_TOKEN_FILE`. Файл не должен попадать в Git или логи. Авторизация передается заголовком; межхостовая переадресация такого запроса запрещена. Поиск получает до трех кандидатов релиза и подробности треклиста/издания. Название релиза не подменяет название трека. Загрузка изображений Discogs выключена. [Discogs API](https://www.discogs.com/developers/), [клиент проекта](https://github.com/discogs/discogs_client).

Чтобы передать новые переменные в контейнеры, добавьте их в environment сервиса app и worker через локальный compose override. Базовая production-конфигурация дополнительные каталоги не включает. Отсутствие ключа, 429 и сетевые отказы возвращаются как состояния источника. Кеш и дневной бюджет общие с остальными провайдерами. Контракт проверен тестовыми ответами; живой Discogs без ключа не проверен.

ACRCloud/AudD/AcoustID требуют настроенных ключей и остаются недоступны в бесплатном профиле. Отпечатки ShazamIO и локальный ASR не требуют их. ASR не устанавливает исполнителя.

Альбомный ReplayGain использует [libebur128](https://github.com/jiixyj/libebur128): совместный порог громкости нескольких потоков, целевой уровень -18 LUFS, отдельные track/album gain и true peak. Он не является средним арифметическим усилений треков. Запись меняет только теги; ограничитель пиков и коррекция Opus output-gain не применяются. Поддержка ReplayGain/R128 конкретным плеером проверяется отдельно.
