# Поддержка CUE

В коллекции выберите фильтр **Альбомы CUE**, откройте альбом и нажмите композицию. Плеер начинает с INDEX 01 и останавливается у следующей композиции в том же файле либо у конца файла. Шкала плеера показывает время исходного файла. CUE с несколькими FILE поддерживается, включая переход FILE между INDEX 00 и INDEX 01.

Поддерживаются внешние музыкальные `.cue`, UTF-8 (с BOM и без), UTF-16 с BOM и Windows-1251. Расширение проверяется без учета регистра. UTF-8 проверяется первым, Windows-1251 используется как резервная кодировка; другие устаревшие кодировки нужно предварительно преобразовать в UTF-8. Названия, исполнители, альбом, дата, жанр и индексы сохраняются в каталоге. Поиск включает названия дочерних композиций. Поврежденные CUE и отсутствующие зависимости показываются с ошибками и статусом «Нужно проверить».

Время MM:SS:FF имеет 75 кадров в секунду. INDEX 00 сохраняется как записанный pregap; PREGAP/POSTGAP не сдвигают позиции в исходном файле. Это предварительное прослушивание по границам INDEX 01, без генерации gapless-образа и без воспроизведения синтетических пауз. Семантика команд: [GNU CUE sheet format](https://www.gnu.org/software/ccd2cue/manual/html_node/CUE-sheet-format.html).

Сначала проверяется точное имя FILE. Если его нет, разрешено однозначное совпадение без учета регистра или единственный одноименный lossless-файл (например, WAV в старом CUE и FLAC на диске). Такое сопоставление видно в предупреждениях. Несколько кандидатов считаются ошибкой. Подмена имени внутри CUE не производится.

Ссылки ограничены рабочей коллекцией: абсолютные пути, переходы `..`, URL, символические ссылки и бинарные образы дисков отклоняются. Аудио доступно только после авторизации. Перед прослушиванием проверяются SHA-256 самого CUE и сигнатура аудио (размер, mtime, inode, device); при изменении требуется сканирование. Это не проверка полного хеша большого аудиофайла при каждом Range-запросе.

CUE и связанные образы с несколькими композициями доступны только для чтения. API и worker блокируют изменение, откат и публикацию такого образа. Аудит декодирования исходного аудиофайла разрешен. Обычный однотрековый файл из многофайлового CUE сохраняет существующие возможности редактирования. После изменения аудио CUE нужно пересканировать. Файлы не разделяются, не перекодируются, исходная коллекция не меняется. Автоматическое воспроизведение следующего трека, встроенный FLAC CUESHEET, редактирование CUE, экспорт отдельных треков и синхронизация дочерних LRC пока не реализованы. Воспроизведение зависит от поддержки исходного кодека браузером.

Проверки: синтетические файлы проверяют кодировки, 75 кадров/с, несколько FILE, INDEX 00/01, неоднозначные ссылки, недопустимые пути, устаревшие зависимости, авторизованный Range и блокировку записи. Реальная коллекция проверяется отдельно после развертывания; частичное сканирование с другими поврежденными файлами не означает ошибку всех CUE.
